# Sanayei Panel on Railway

## Quick Deploy

1. Push this repository to GitHub
2. Connect to Railway
3. Set environment variables
4. Deploy

## Environment Variables

- `ADMIN_USERNAME`: Panel admin username (default: admin)
- `ADMIN_PASSWORD`: Panel admin password (auto-generated if empty)
- `SECRET_KEY`: Panel secret key (auto-generated if empty)

## Access

After deployment, Railway provides a URL like:
`https://sanayei-panel-production.up.railway.app`
